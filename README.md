# CASEVO

A polished, responsive English landing page for CASEVO with a restrained Chinese-inspired visual direction.

## Deploy to Vercel

This is a static site. No build command is required.

1. Upload `index.html`, `style.css`, `script.js`, and `README.md` to your GitHub repository.
2. In Vercel, import the GitHub repository.
3. Framework Preset: **Other** (or leave auto-detected).
4. Build Command: leave empty.
5. Output Directory: leave empty.
6. Click **Deploy**.
7. Add `getcasevo.com` under Project → Settings → Domains.

The email form is currently front-end only. Connect it to your preferred email/form backend when ready.
